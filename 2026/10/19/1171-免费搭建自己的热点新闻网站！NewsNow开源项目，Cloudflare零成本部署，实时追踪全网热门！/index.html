免费搭建自己的热点新闻网站！NewsNow开源项目，Cloudflare零成本部署，实时追踪全网热门！

· 2026-10-19 · 次阅读

每天刷新闻，是不是总要打开好几个平台？想看看今天有什么热门话题，又不想在各种网站之间来回切换？🤔

今天给大家分享一个实用的开源项目：NewsNow！一个可以聚合多个平台热门新闻的阅读工具，界面简洁、支持实时热点更新，还可以尝试通过 Cloudflare Pages 免费部署，搭建属于自己的新闻聚合网站！ 🔥

如果你平时喜欢关注热点、研究开源项目，或者想自己搭建一个新闻阅读页面，这个项目值得体验一下。

🌟 一、NewsNow是什么？

NewsNow 是一个开源的热门新闻聚合项目，主要解决新闻来源分散、查看热点需要频繁切换平台的问题。

它能够集中展示多个信息来源的热门内容，让你在一个页面里快速浏览当前的热门话题。

与传统新闻网站相比，NewsNow 更注重简洁的阅读体验。打开页面，就可以直接查看聚合的热点内容，不需要在多个网站之间反复跳转。

对于想了解互联网热点、科技资讯以及各个平台热门话题的用户来说，这种方式更加方便。📱

而且，它是一个开源项目，不仅可以直接体验，还能根据自己的需求研究和部署。

💡 二、NewsNow能解决哪些用户痛点？

😵 1. 新闻平台太多，查看热点太麻烦

平时想了解热门话题，可能需要分别打开不同的网站或应用。

一个平台看完，再切换到另一个平台，时间久了不仅麻烦，也容易错过其他来源的热门内容。

NewsNow 可以将多个来源的热点集中展示，让你在一个页面中快速了解不同平台正在讨论什么。

⏰ 2. 想追踪热点，却没有那么多时间

对于经常关注互联网动态、科技新闻和社会热点的人来说，每天手动搜索信息是一件比较耗时的事情。

NewsNow 支持热门内容更新，并根据信息来源的更新频率调整抓取间隔，默认缓存时间为30分钟。

这样可以减少频繁请求带来的资源消耗，也让热点阅读更加方便。

需要注意，具体内容的更新时间取决于对应信息源，并不代表每条新闻都会实时同步。

🧹 3. 只想看热点，不想面对复杂页面

有些新闻页面包含大量栏目、推荐内容和其他信息，用户真正想看的热点反而不够突出。

NewsNow 的设计更加注重简洁和阅读体验，方便用户快速浏览热门内容。

如果你喜欢干净、直接的新闻阅读界面，可以试试这个项目。✨

💸 4. 想搭建新闻网站，又不想购买服务器

如果自己开发一个新闻聚合网站，不仅需要考虑前端页面，还要处理部署、运行环境和后续维护。

NewsNow 已经提供了现成的开源代码，可以省去从头开发界面的工作。

配合 Cloudflare Pages，可以尝试利用免费套餐部署基础版本，降低网站搭建成本。

不过，具体能否长期零成本运行，还要看项目配置、资源用量及 Cloudflare 当前套餐限制。

🛠️ 三、NewsNow有哪些核心功能？

🔥 1. 多来源热门新闻聚合

NewsNow 的核心功能就是聚合不同来源的热门内容。

不用每次都单独打开不同平台，可以直接在聚合页面查看热门话题，更方便地了解当下的网络热点。

对于喜欢关注互联网趋势、科技动态和热门事件的用户来说，这是一项非常实用的功能。

⚡ 2. 热点内容自动更新

项目支持热门新闻更新，并会根据不同信息源的更新频率调整抓取间隔，最短间隔为2分钟。

这样既能兼顾内容更新，也可以避免过于频繁地请求来源网站。

需要说明的是，抓取间隔并不等于每隔2分钟所有新闻都会更新，实际更新速度还取决于来源网站。

🎨 3. 简洁清爽的阅读界面

NewsNow 强调简洁的用户界面，让用户能够把注意力集中在新闻内容上。

不需要复杂的操作，就可以快速浏览热点，适合日常阅读和快速获取信息。

🔐 4. 支持GitHub登录

项目支持 GitHub OAuth 登录及数据同步。

如果需要使用登录相关功能，就需要按照项目文档配置 GitHub App、回调地址和相应的环境变量。

对于只想体验基础新闻聚合功能的用户，可以先了解基础部署方式，不必一开始就配置所有高级功能。

🔄 5. 支持手动刷新

项目默认缓存时间为30分钟，登录用户可以强制刷新获取最新数据。

如果你想查看更新的热点内容，这个功能会比较方便。

🤖 6. 支持MCP服务端

NewsNow 还支持 MCP 服务端，可以按照项目文档进行配置，并尝试与兼容 MCP 的工具配合使用。

对于喜欢研究 AI 工具、自动化工作流的开发者来说，这也提供了更多探索空间。

具体能否完成某项操作，还需要看所使用的客户端和 MCP 配置。

☁️ 7. 支持Cloudflare Pages部署

项目官方提供了 Cloudflare Pages 的基础部署说明。

如果你不想购买服务器，可以将项目导入 Cloudflare Pages，按照要求完成构建和部署。

这也是本项目比较吸引人的地方：不需要从零开始开发新闻网站，就有机会通过现成的开源代码搭建自己的热点聚合页面。

☁️ 四、如何通过Cloudflare零成本部署NewsNow？

如果你平时关注免费建站、Cloudflare部署或者开源项目，那么 NewsNow 很适合拿来体验。

我已经录制了 NewsNow详细搭建教程视频，会演示如何部署这个项目，帮助大家更容易上手。🎬

根据项目官方文档，基础部署可以按照以下思路进行：

  1. 🐙 将 NewsNow 项目 Fork 到自己的 GitHub 账号。
  2. ☁️ 登录 Cloudflare，进入 Pages 部署相关页面。
  3. 🔗 将自己的 GitHub 仓库连接到 Cloudflare。
  4. ⚙️ 按照项目要求填写构建配置。
  5. 🚀 启动部署，等待构建完成。
  6. 🌐 打开生成的网站地址，检查新闻页面是否正常显示。

注意： 基础部署适合不需要登录和缓存功能的场景。如果想启用完整的登录、数据库和缓存功能，还需要进一步配置相关环境变量及数据库。Cloudflare 的具体部署能力也可能随平台规则调整，请以项目文档和控制台实际提示为准。

💰 五、部署NewsNow需要花钱吗？

这是很多人比较关心的问题。

NewsNow 本身是开源项目，可以获取代码并自行部署。搭配 Cloudflare Pages 的免费套餐，可以尝试以较低成本运行基础版本。

如果只是个人体验、学习部署，或者搭建一个自己的新闻阅读页面，可以优先尝试免费方案。

但需要注意以下几点：

  • 🆓 开源代码不代表所有运行服务都免费。
  • ☁️ Cloudflare 免费套餐存在使用限制。
  • 🗄️ 登录、缓存等功能可能需要额外配置数据库。
  • 🌐 自定义域名如果需要单独购买，可能产生费用。
  • ⚙️ 超出免费额度或使用其他收费服务时，可能产生额外开支。

因此，更准确地说，NewsNow 可以尝试通过 Cloudflare 免费套餐实现低成本甚至零成本部署，但不应保证所有配置和所有使用场景都永久免费。

📱 热点资讯爱好者

🛠️ 个人网站搭建者

想拥有一个自己的新闻聚合页面，方便日常查看热点，也可以将它作为个人项目进行学习和研究。

对于没有部署经验的朋友，直接看项目源码可能会觉得有些复杂。

NewsNow 是一个值得体验的开源热门新闻聚合项目，主要特点包括：

如果你厌倦了在多个新闻平台之间来回切换，或者想学习如何利用 Cloudflare 免费套餐搭建网站，不妨试试 NewsNow。
