别再花钱买监控服务！利用Cloudflare免费资源搭建专属Server监控系

· 2026-8-10 · 次阅读

很多站长都有一个痛点：

服务器到底稳不稳定？

CPU 有没有爆？

内存是不是快满了？

硬盘还能撑多久？

网站访问慢，到底是程序问题，还是服务器问题？

以前很多人会选择安装宝塔、1Panel、Prometheus 等大型监控系统。

但是问题来了：

❌ 安装复杂
❌ 占用资源
❌ 配置麻烦
❌ 小服务器根本跑不动

特别是一些只有 1核1G、2核2G 的 VPS，安装一堆监控服务，反而拖慢服务器。

有没有一种：

✅ 简单
✅ 免费
✅ 开源
✅ 轻量
✅ 浏览器直接查看

的服务器监控方案？

今天分享一个 GitHub 上的开源项目：

🔥 CF-Server-Monitor

一个专为 Cloudflare 生态打造的服务器状态监控面板。

🌟 它解决了什么问题？

很多个人站长都有这样的经历：

晚上睡觉前网站还正常。

第二天起来：

“网站怎么打不开了？”

登录服务器：

CPU 100%

内存爆满

磁盘满了

服务停止

但是你完全不知道什么时候发生的。

服务器监控的意义，就是：

在问题发生之前，提前发现风险。

CF-Server-Monitor 就是帮助你实时了解服务器健康状态。

🖥️ 一个页面，看懂服务器所有情况

打开面板后，你可以看到：

1️⃣ CPU 实时监控

查看：

  • CPU 使用率

  • 实时变化曲线

是不是：

  • 网站被攻击？

直接打开网页即可。

✅ 总内存大小
✅ Swap 交换分区

搭建教程：

第一步：Fork 项目
点击右上角 Fork 按钮，将项目 Fork 到你的 GitHub 账户。

第二步：新建 Cloudflare Workers
登录 Cloudflare 控制台
进入 Workers & Pages
点击 Create application
选择 Continue with GitHub（第一次使用需要连接 GitHub 账户），选择本项目
Project Name填写：cf-server-monitor
Build command 填写：npm run build:frontend
Deploy command 保留默认值：npx wrangler deploy
点击 Deploy，成功会在底部显示✨ Success! Build completed.

第三步：配置环境变量
在当前Workers & Pages页面，点击 Settings
在Variables and secrets找到API_SECRET，点右侧编辑，填写密码（建议使用随机数,不要包含特殊字符比如%），点Deploy保存部署，等待30秒左右部署完成

第四步：绑定自定义域名，后台管理与设置访问后台地址/admin, 默认用户名admin，默认密码是刚才API_SECRET的值。
