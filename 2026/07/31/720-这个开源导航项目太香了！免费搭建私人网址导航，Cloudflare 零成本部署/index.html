这个开源导航项目太香了！免费搭建私人网址导航，Cloudflare 零成本部署

· 2026-7-31 · 次阅读

不知道大家有没有这种感觉👇

浏览器收藏夹越来越乱。

AI 工具越来越多。

平时工作要用的网站越来越杂。

真正想找的时候，反而找不到……😅

前段时间一直在找一款导航程序。

要求其实很简单：

✅ 页面好看

✅ 手机端体验好

✅ 免费部署

✅ 不用买服务器

✅ 最好还能支持权限管理

前前后后试了不少项目。

有的后台太复杂，有的手机端体验一般，还有的部署步骤特别繁琐。

直到发现了 iori-nav。

第一眼给我的感觉就是：

💡 不像传统的网址导航，更像一个现代化的资源管理平台。

整个页面干净清爽，动画流畅，电脑、手机都很好看。

✨ 为什么推荐 iori-nav？

真正让我留下来的，不只是颜值，而是它几个非常实用的功能。

☁️ Cloudflare 免费部署

这是我最喜欢的一点。

整个项目支持 Cloudflare 免费部署。

也就是说：

✅ 不用买服务器

✅ 不用自己维护环境

✅ 自动 HTTPS

✅ 全球 CDN 加速

✅ GitHub 自动部署

如果已经有 GitHub 仓库，只需要连接 Cloudflare，配置一下构建命令，后续每次提交代码都会自动更新。

对于个人站长来说，真的非常省心。

🔒 自带密码保护

有时候，并不是所有导航都希望公开。

比如：

🌐AI 工具后台

🌐各类服务管理面板

🌐个人资源链接

🌐私密收藏网址

iori-nav 自带密码保护。

没有密码，就无法进入页面。

安全性一下子提高不少。

🙈 支持私密分类

这个功能我觉得特别贴心。

很多导航程序只有”显示”和”隐藏”。

iori-nav 可以直接设置：

🌍 公开分类

🔐 私密分类

管理员登录后，可以查看全部内容。

普通访客只能看到公开部分。

对于团队协作或者个人管理都非常方便。

👨‍💻 管理员权限查看

管理员拥有完整权限。

可以查看：

✔ 所有分类

✔ 私密导航

✔ 后台管理

普通用户则只能浏览公开内容。

权限划分很清晰。

💻 电脑端展示效果

📱 手机端展示效果

🎨 页面颜值是真的在线

第一次打开的时候，我最大的感觉就是：

舒服。

不是那种十年前的网址导航风格。

而是现代卡片布局。

整个页面看起来非常干净。

我比较喜欢这些细节：

✨ 卡片式设计

✨ 图标自动识别

✨ 响应式布局

✨ 深浅色主题

✨ 分类切换丝滑

手机端和电脑端基本保持一致。

这一点真的很加分。

🎯 适合哪些人？

如果你属于下面这些类型，我觉得都值得试试：

🤖 AI 工具导航

💼 企业内部导航

🎓 学习资源整理

💻 开发者工具导航

🎨 设计资源导航

📚 个人网址收藏

几乎所有需要整理网址的人，都可以用它。

❤️ 最后说几句

现在市面上的导航程序很多。

但真正让我愿意长期使用的不多。

iori-nav 给我的感觉就是：

不是一味追求功能堆砌，而是真正把体验做好了。

尤其是：

✅ 免费开源

✅ Cloudflare 免费部署

✅ 手机、电脑双端适配

✅ 自带密码保护

✅ 支持私密分类

✅ 管理员权限管理

如果你最近也准备搭建一个：

🌐 AI 导航

🌐 网址导航

🌐 企业导航

🌐 学习导航

🌐 工具导航

那么可以体验一下这个项目。
